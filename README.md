# ИИ-ассистент санатория-профилактория «Лукоморье»

Готовый серверный RAG-ассистент и встраиваемый чат-виджет. База знаний сформирована из постоянных разделов сайта `aolukomorie56.ru`, двух предоставленных прейскурантов и консервативных справок по процедурам. Новости и акции не включены.

## Что внутри

- строгий RAG: ответ формируется только из найденных фрагментов базы;
- точный поиск цен и статуса услуг из прейскурантов;
- семантический поиск через `text-embedding-3-small` и резервный лексический поиск;
- Responses API OpenAI с `store: false`;
- SQLite-кеш ответов и эмбеддингов;
- ограничение частоты запросов, CORS и отсутствие журналирования текста сообщений;
- виджет в правом верхнем углу с маркировкой «ИИ» и медицинским предупреждением;
- Docker-развертывание на Ubuntu/VPS.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY`, `PUBLIC_BASE_URL` и `ALLOWED_ORIGINS`.
2. Запустите:

```bash
docker compose up -d --build
docker compose exec assistant python -m app.ingest
```

3. Проверьте `https://ВАШ-ДОМЕН/health` и откройте `https://ВАШ-ДОМЕН/demo`.

Индекс создается автоматически при первом запросе, но отдельная команда `ingest` удобнее: она заранее построит эмбеддинги. Без ключа OpenAI работает только лексический поиск и диагностический endpoint; ответы пользователям не генерируются.

## Установка виджета на aolukomorie56.ru

Добавьте перед закрывающим `</body>`:

```html
<script
  src="https://bot.example.ru/widget.js"
  data-api="https://bot.example.ru/api/chat"
  data-position="top-right"
  defer></script>
```

Для WordPress это можно сделать в дочерней теме или через плагин вставки кода. В `ALLOWED_ORIGINS` укажите `https://aolukomorie56.ru,https://www.aolukomorie56.ru`.

## Обновление базы

Отредактируйте `data/knowledge.json`, затем выполните:

```bash
docker compose exec assistant python -m app.ingest --rebuild
```

Для каждой услуги сохранены цена, длительность, доступность и источник. Пометки исходного файла вроде «нет», «не работает» и «не читают» превращены в статус `unavailable`/`limited`; ассистент не должен предлагать такую услугу как доступную.

## Продакшен

- Проксируйте контейнер через HTTPS (пример для Nginx — `deploy/nginx.conf`).
- Не публикуйте порт `8080` напрямую, если используется обратный прокси.
- Храните `.env` только на сервере; файл исключен из Git.
- Установите DNS-запись, выпустите TLS-сертификат и замените `bot.example.ru`.
- Перед публикацией попросите главного врача проверить `procedure_guides` и статусы оборудования: противопоказания зависят от диагноза, аппарата и методики.

## Проверка

