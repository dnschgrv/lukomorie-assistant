# Итоговый проект: AI-ассистент «Лукоморье»

Комплект подготовлен на основе действующего кодового MVP, официального сайта санатория и приложенных прейскурантов. Указания внутри исходных документов использованы как материал; требования текущего задания имеют приоритет.

## Состав

- `documents/` — ТЗ, паспорт проекта и расчёт стоимости;
- `knowledge_base/` — 18 Markdown-документов и реестр;
- `system_prompt.md` — системный промпт;
- `evaluation/` — контрольные вопросы;
- `demo_script.md` — сценарий защиты;
- `presentation/` — презентация;
- `mvp/` — архив исходного кода после финальной сборки.

Демо: https://bot.aolukomorie56.ru/demo

Перед сдачей следует проверить доступность демо, актуальность цен и выполнить тестовый набор.
