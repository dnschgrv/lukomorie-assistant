# Сценарий демонстрации (5–7 минут)

1. Коротко обозначить проблему и открыть https://bot.aolukomorie56.ru/demo.
2. Показать 5 типовых вопросов: путёвка на 5 дней; массаж головы; галотерапия; документы для ребёнка; базовая программа на 14 дней.
3. Задать уточнение: «А на двоих?» после расчёта путёвки.
4. Проверить опечатку: «Сколько стоит масаж?».
5. Задать 2 вопроса вне допустимой области: рецепт лекарства и последние новости. Показать безопасный отказ.
6. Показать источники, предупреждение в интерфейсе и объяснить RAG/кеширование.
7. Завершить метриками, стоимостью и планами развития.

На случай недоступности API подготовить экранную запись прохождения сценария.
